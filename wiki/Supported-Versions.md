# Supported Versions

Some files cover several Minecraft versions. Such a file is offered only where it was started and
tested **unchanged on every version it lists**. There is no file that claims an open range.

## Which file do I need?

| Minecraft | Fabric | NeoForge |
|---|---|---|
| 1.21.1 | `avcme-<version>+mc1.21.1-fabric.jar` | `avcme-<version>+mc1.21.1-neoforge.jar` |

## What "tested" means

For every version above, the exact file from the table was started as a client and as a dedicated
server, ran all automated game tests, ran again together with each supported other mod that exists
for that version, and was played by hand before the release.
